최근 자동 게시글

0 articles
처음 사용하는 경우 · 자동 게시 설정
  1. 변경 파일을 GitHub 저장소의 기본 브랜치에 반영합니다.
  2. 저장소 Settings → Secrets and variables → Actions에서 OPENAI_API_KEY Secret을 등록합니다. API 키를 이 페이지에 입력하지 않습니다.
  3. Settings → Pages의 Source를 GitHub Actions로 설정합니다.
  4. Actions의 Daily Trending Posts에서 Run workflow를 실행합니다. 이후 매일 오전 9시에 예약 실행됩니다.

기본 요약 모델은 gpt-4.1-mini입니다. Actions 변수 OPENAI_MODEL로 변경할 수 있으며 API 사용료가 발생합니다. 오늘 증가한 Star 기준은 TRENDING_SORT=daily로 설정합니다.

로컬 실행: python scripts/trending_posts.py로 글을 생성한 뒤 python -m http.server 8000 --bind 127.0.0.1로 블로그를 열 수 있습니다. 로컬 파일을 더블클릭하는 방식에서는 게시 파일을 불러올 수 없습니다.

이 페이지는 예약 서비스의 활성 상태를 직접 조회하지 않습니다. 실제 실행 성공·실패는 위 실행 기록에서 확인하세요.

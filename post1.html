첫 번째 블로그 게시물

이것은 첫 번째 블로그 게시물의 전체 내용입니다. 이 페이지는 개별 블로그 게시물이 어떻게 보일지를 보여주기 위해 만들어졌습니다.

기술 블로그는 배운 것을 정리하는 가장 좋은 방법입니다. 아래는 간단한 코드 예시입니다.

function greet(name) {
  return `Hello, ${name}!`;
}
코드는 사람을 위해 쓰여야 한다. 컴퓨터가 실행할 수 있는 코드는 부수효과일 뿐이다. — Robert C. Martin
